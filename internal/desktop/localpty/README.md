# Native local PTY boundary

`Process` owns the local child and PTY I/O, resize, exit status and shutdown. The terminal manager owns session IDs, replay/backpressure, transfers and UI events. Native handles never cross the renderer bridge.

The Unix implementation wraps the existing creack/pty process. The Windows implementation creates a ConPTY with independent input/output pipes and `STARTUPINFOEX`, using x/sys APIs already in the project. Arguments use Windows escaping; the explicit UTF-16 environment block is sorted, NUL-checked and double-terminated. Child-only pipe handles close after creation, and thread/process/console handles have explicit owners. The manager starts one waiter per process and kills/closes on session shutdown. Natural exit waits for the output reader before publishing final state and closes the transport while retaining canonical replay. A two-second inherited-pipe grace period is extended while the renderer is paused and after it resumes; explicit close/context cancellation wakes exit cleanup. On natural Windows process exit, Wait closes the pseudoconsole while the independent output reader drains final frames through EOF. Explicit shutdown closes communication pipes before closing the console so a stopped consumer cannot deadlock teardown. The console handle is detached under a lock, which is released before the native close; a simultaneous shutdown can still close pipes to release the drain. No cursor-inheritance handshake is requested.

Windows shell selection follows the Electron order: PowerShell 7, Windows PowerShell, COMSPEC, cmd.exe. Unix selects the effective account's login shell before SHELL and /bin/sh, matching Electron. CGO builds query the native account service through getpwuid_r; static builds use /etc/passwd and do not claim directory-service/NSS support beyond local accounts. Lookup errors are surfaced to the caller. PowerShell launches with the Electron-compatible UTF-16LE encoded prompt wrapper. It calls the user prompt before emitting a private nonce-tagged cwd OSC report for FileSystem providers. A bounded streaming observer handles split reports without modifying terminal bytes. Unix cwd polling is skipped on Windows; cmd.exe retains its initial cwd because it has no PowerShell prompt reports.

Real Unix PTY tests cover initial dimensions, resize/input, PID, nonzero exit and kill; existing manager tests cover replay, flow control and cleanup. Windows-only tests cover shell selection/environment formatting and a real cmd.exe ConPTY marker/resize/exit path. A further native PowerShell test changes into a directory containing spaces, Chinese characters and an apostrophe and waits for its reported cwd. These tests must run on Windows; cross-compilation is not runtime validation. The actual Electron oracle additionally covers launch args and chunked/malformed directory reports on the development platform.

The native API lifecycle follows [Microsoft's ConPTY guidance](https://learn.microsoft.com/en-us/windows/console/creating-a-pseudoconsole-session). Native Windows Unicode/IME, heavy output, cancellation/handle leakage, child-tree shutdown and terminal/file integration still require acceptance.
